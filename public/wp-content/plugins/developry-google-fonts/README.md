## USAGE

Once you have successfully installed and activated the [**Web Fonts Loader**](https://bit.ly/4adYstE) plugin, your Classic Editor toolbar will be enhanced with two new dropdown menus containing all the available font options.

### Editor Toolbar Customization:

- **Font Typeface Selection:** The first dropdown in your editor toolbar lets you select the font family. Browse through a variety of Google Fonts to find the perfect match for your content.
- **Font Weight and Style Selection:** The second dropdown is for font weight and style. Choose from various font weights (from Thin to Black) and styles, including italic versions.

### Applying Fonts Site-Wide:

Go to `Web Fonts Loader` in your WordPress admin submenu.

This section lets you apply your chosen fonts universally across your site.

Select fonts for your site's headings and body text to create a consistent and cohesive design.

### Tips for Optimal Use:

- **Maintain Consistency:** Consistent font usage ensures a professional and cohesive web design.

By following these tips, you can enhance the visual appeal and readability of your WordPress site with the [**Web Fonts Loader**](https://bit.ly/4adYstE) plugin.

### Is WordPress Gutenberg Block Compatibility Available?

Currently, the plugin does not support Gutenberg blocks. However, you can explore [**Web Fonts Loader Pro**](https://bit.ly/4adYstE), which offers this functionality and more.

If you prefer to use the plugin, you can still do so by using the Classic Editor or setting global fonts through the plugin's options page.

### How to Apply a Font Family or Weight to All Text on a Specific Page or Post?

To apply a specific font family or weight, select your desired option without highlighting any text in the editor.

### Applying Fonts to a Lead Paragraph or Heading

To apply a font to a specific paragraph or heading, double-click on the text of the element. This will select the entire text, allowing you to assign your desired font family or weight.

### Identifying the Font Family or Weight on an Element

To identify the font family or weight applied to an element, click on it once. If a Google font family or weight is applied, the Toolbar options will display the details.

### Applying Font Family or Weight Site-Wide

Go to **Appearance > Web Fonts Loader** in your WordPress admin menu. There, you'll find all the settings needed for global font application.

_Note: Applying fonts and styles to individual elements through the Classic Editor will override global font settings._

## INSTALLATION

The plugin installation is easy and straightforward. Let us know if you run into any issues.

= Installation from WordPress =

1. Go to **Plugins > Add New**.
2. Search for **Web Fonts Loader**.
3. Install and activate the plugin.
4. Click **Settings** or go to **Web Fonts Loader** in the menu.

= Manual Installation =

1. Upload the `developry-google-fonts` folder to `/wp-content/plugins/`.
2. Go to **Plugins**.
3. Activate the **Web Fonts Loader** plugin.
4. Click **Settings** or navigate to **Web Fonts Loader** in the menu.

= After Activation =

1. Select global fonts from **Web Fonts Loader**.
2. Edit any Post or Page using the Classic Editor to access additional options for font family and weight in the toolbar.
